Corrección del error por el que el hangar aparecía encima de Jugar, Continuar, Opciones y Mapa.
Causa: regla CSS #hangar { display:flex!important } prevalecía sobre .hidden { display:none!important }.
Solución: #hangar.hidden { display:none!important } con prioridad correcta.
